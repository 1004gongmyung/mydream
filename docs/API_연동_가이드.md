# 마이드림 외부 API 연동 가이드

> 상태(2026-07-28): **커리어넷 = 정적 스냅샷 방식으로 연동 구축** — 키를 로컬에서만 쓰고, 수집 결과를 정적 데이터로 배포한다.
> 원칙: 키가 없을 때 가짜 데이터를 만들지 않는다(스냅샷 available:false → 아무것도 표시 안 함).

## 커리어넷 스냅샷 연동 (구축 완료)

**왜 스냅샷인가**: 공개 저장소·정적 사이트라 ① 키를 코드에 넣을 수 없고 ② 브라우저 직접 호출은 CORS·키 노출·사용자별 호출량 문제가 있다. 로컬에서 키로 받아 정적 파일로 배포하면 전 사용자에게 작동하고 API 장애와도 무관하다(개발참고자료 §8의 "응답 캐시+주기 갱신" 원칙 구현).

**갱신 절차** (분기 1회 권장):
1. 인증키를 `mapsi-app/.careernet.key` 파일에 저장 (이 파일은 .gitignore — 절대 커밋되지 않음)
2. `node tools/fetch-careernet.mjs` → 직업백과 전체 목록 + 앱 수록 직업(조건 카드·사전·도감)과 매칭되는 상세(하는 일·되는 길·관련 자격·관련 학과·임금)를 `data/careernet.data.js`로 생성
3. 테스트·스윕 → `index.html`의 `?v=` 올리고 push

**앱 표시 위치**: ① 조건 카드 상세·직업 사전 카드에 "커리어넷 직업 정보" 섹션(출처 칩 ②+수집일) ② 검색 최종 폴백 — 사전에 없는 직업도 커리어넷 전체 목록에서 인식.

## 1. 무엇을 연동하나

| 대상 | 제공 기관 | 용도 (앱 내 위치) |
|---|---|---|
| 커리어넷 오픈API | 교육부·KRIVET | 직업백과·학과정보(조건 카드 보강), 진로심리검사 연계(A3·A4의 검사 바로가기 → 결과 해석) |
| 한국고용정보원 API (공공데이터포털) | 고용노동부 | 직업별 임금·전망(조건 카드의 '임금 분포' 섹션 — 현재 "연동 후 표시" 상태), 자동화 전망(A7 `[직업별 수치 연동]` 마커) |

## 2. 키 발급 절차

### 커리어넷
1. https://www.career.go.kr → 오픈API 안내 페이지에서 API 인증키 신청 (무료)
2. 발급받은 키를 앱에서 등록: 브라우저 콘솔에서
   `localStorage.setItem("mapsi.api.keys", JSON.stringify({ careernet: "발급키" }))`

### 공공데이터포털 (고용24·한국고용정보원)
1. https://www.data.go.kr 회원가입 → "한국고용정보원" 검색
2. 원하는 API(직업정보, 직업심리검사 등) **활용신청** → 자동승인 키 발급
3. 등록: `localStorage.setItem("mapsi.api.keys", JSON.stringify({ work24: "발급키" }))`

## 3. 코드 연결 지점

- `js/api.js` — 어댑터. `fetchJobDetail()` 등의 TODO 블록에 실제 호출을 구현한다.
- `js/app.js` `renderJob()` — 임금 섹션이 `JOBS.wagePendingNote`를 보여주는 자리에서 `MapsiApi.fetchJobDetail()` 결과로 교체한다.
- 연동 원칙 (개발참고자료 §8): **API 장애 시에도 앱이 동작해야 한다** — 응답 캐시(정적 스냅샷) + 주기 갱신 구조로 구현할 것.

## 4. 주의

- 키를 코드·저장소에 하드코딩하지 말 것 (localStorage 또는 서버 환경변수).
- CORS: 공공 API 일부는 브라우저 직접 호출이 막혀 있다 → 그 경우 간단한 프록시(서버리스 함수)가 필요하며, 이는 배포 단계에서 결정한다.
- 표시 원칙 유지: API 수치에도 반드시 출처 칩(②공공기관)과 기준 연도를 붙인다.
