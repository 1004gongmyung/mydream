# 성직자 진로 모듈 — 데이터 갱신 절차와 중립성 원칙

> 설계 원본: `../../mydream-clergy-path-module-prompt.md`
> 목적: 공공 진로 플랫폼이 다루지 않는 성직 경로를 **중립적인 직업 정보**로 안내한다. 포교가 아니다.

## 중립성 원칙 (코드 리뷰 기준)

1. **포교가 아니라 직업 정보** — 교리 설명·신앙 권유·종교 간 비교 금지. 다른 직업 카드와 동일 컴포넌트(qcard·cluster-card), 전용 CSS 금지(테스트 강제).
2. **모든 종교 동시 수록** — 빌드 가드: 개신교·천주교·불교 각각 실데이터 경로 1건 미만이면 **모듈 전체 비노출**(샘플 행은 판정 제외). 한 종교만 보이는 상태는 포교 앱으로 읽힌다.
3. **종단 공식 기관까지만** — 교단 총회·종단 교육원·인준 양성기관 허용. 개별 교회·성당·사찰 금지(verify 스크립트가 기관명 패턴 경고).
4. **정통성 판정 금지** — 이단·사이비 표기 금지. 미수록 기관 검색 시 "확인되지 않은 기관 — 인준 여부는 해당 교단 총회에서 확인" 안내만.

## 확정 수록 범위 (2026-07-27 기획 결정)

개신교(주요 교단별 인준 신학대 매칭) · 천주교 · 불교 (최소 요구 3종) + 원불교 + 성공회(선택) + 이슬람("국내 인가 양성기관 없음 — 공식 창구는 한국이슬람교중앙회"라는 사실 카드). 그 외는 미수록 — 판정 없이 범위 밖.

## 구조

```
data/clergy_paths.seed.csv          경로 (religion·denomination·role·미성년 진입 여부·상담 창구·출처·기준일)
data/clergy_stages.seed.csv         단계 (is_reversible 핵심 — false면 reversibility_note 필수)
data/training_institutions.seed.csv 양성기관 (교단 인준 / 학위 인정 — 두 축 분리, 합치기·파생 금지)
data/exploratory_steps.seed.csv     중간 실험 (전부 되돌릴 수 있는 활동만 — 이 모듈의 가장 중요한 콘텐츠)
tools/load-clergy.mjs               4개 CSV 조인 → data/clergy.data.js (필수 필드·안전장치·가드 판정)
tools/verify-clergy-data.mjs        빌드 가드·180일·출처 URL·미성년 전화 필수·개별 시설 패턴
js/clergy.js                        로직 — 가드·2축 배지·가나다 정렬·검색·안전장치 판정 (UMD, 테스트 대상)
test/clergy.test.mjs                스펙 5종 + 중립성 + 절대 규칙
화면: #clergy(단일 목록·탭 없음·기관 검색) / #clergy/<id>(7단 고정 순서)
진입점: 조건 카드(#jobs) 하단 — 가드 통과 시에만 렌더
```

상세 화면 순서(고정): 하는 일 → **지금 해볼 수 있는 것**(비가역 단계보다 먼저) → [미성년 안전장치] → 전체 단계(비가역 경고 배지) → 양성기관(배지 2개) → 솔직하게 말하면 → 공식 상담 창구 → 기준일·출처·"최종 확인은 해당 종단에 문의".

## 데이터 갱신 절차

1. **원본 확인** — 각 종단 공식 사이트로 한정: 교단 총회(예장통합·합동 등), 천주교주교회의, 조계종 교육원, 원불교 교정원, 성공회 관구, 한국이슬람교중앙회. 학위 인정 여부는 대학알리미로 교차 확인.
2. CSV 4종 편집. 규칙:
   - `is_denomination_approved`(교단 인준)와 `is_accredited_university`(학위 인정)는 **각각 원본에서 확인해 명시 입력** — 서로에게서, 학교 이름에서 파생 금지
   - 미성년 진입 가능(`is_open_to_minors=true`) 경로는 `official_contact_phone` 필수 — 없으면 로더가 거부
   - 비가역 단계(`is_reversible=false`)는 `reversibility_note`(되돌릴 경우 무엇이 남는지 사실만) 필수
   - 모르는 값은 빈칸(null) — 모델·추정으로 채우지 않는다
3. `node tools/load-clergy.mjs` → 스킵 사유 확인 → `node tools/verify-clergy-data.mjs`
4. `node --test test/clergy.test.mjs` + `node tools/audit-links.mjs` → 서버 띄우고 `node tools/sweep.mjs`
5. 통과하면 push (자동 배포). **개신교·천주교·불교 실데이터가 모두 채워지는 커밋에서 모듈이 자동으로 나타난다** — 그 전까지는 '준비 중' 게이트 화면만 보인다.

## 하지 말 것 (원본 프롬프트의 금지 목록)

- 교리 설명, 신앙 권유, 종교 간 비교·평가 / 특정 단체 이단·사이비 표시
- 개별 교회·사찰·성당 데이터 수록 / 종교별 탭 UI·추천·인기 정렬
- 교단명·인준 여부·연령 요건을 모델이 추정해 채우기
- 인준·학위 두 필드를 하나로 합치기 / 자동 크롤러
