## 나침반·역방향 (로드맵 3단계 — 구현 완료)

- **진입은 질문 카드의 L3 버튼으로만** (통합설계: 기능을 입구에 내세우지 않는다) — "나침반 시작"(A1·A11·B3 등) → `#compass`, "역방향 지도"(D1) → `#reverse`, "검사 바로가기"(A3) → 커리어넷 검사 외부 링크
- 나침반: 6축 양자택일(건너뛰기 허용) → 직업군 6~10개 **가설** 제시(단정 금지 — "이런 하루를 사는 사람이 많은 직업군") + 겹친 취향 근거 + 렌즈 한 줄(최대 1개)
- 역방향: "시간이 빨리 가는 과목" 선택(등급 안 물음) → 계열 가설 + 기여 과목 + 이공계 권장과목 안내(D2 답변 연결)
- 결과는 기기(localStorage)에만 저장 — 누적 기록의 시작점

## 안심 DB + 위기 라우팅 (로드맵 4단계 — 구현 완료)

- **검색 기능**: 홈 상단 "지금 고민을 검색해도 돼요" → 질문 63문 매칭(상한 8개). 검색 전 **반드시 위기 감지를 통과** — 위기 계열이면 검색·답변을 실행하지 않고 즉시 안내 화면 전환
- **위기 안내 화면**(`#care-now`): 판단·상담 문구 없이 연결만 — 1388 전화(tel:)·문자(sms:)·사이버상담 채팅 버튼 + "돌아가기" 경로. "마이진로는 상담 도구가 아니라서, 더 잘 들어줄 수 있는 곳으로 연결해요" 명시
- **도움 창구**(`#help`, 안심 DB): 상황 4종(마음/폭력·괴롭힘/알바·일터/학교 밖) × 공공 창구(1388·109·1577-0199·117·112·1366·1350·청소년근로권익센터·꿈드림·cyber1388). 전 화면 하단 푸터에서 진입 가능
- **감지 규칙**: 공백 무시 부분 일치, 과잉 감지가 과소 감지보다 안전(화면에서 되돌아가기 제공). 저널·체크인 등 입력 기능이 추가되면 같은 `MapsiCare.detectCrisis`를 반드시 거칠 것
- 정서 안전 규칙 테스트로 강제: 안심 DB에 진단명·"힘내" 류 판단 표현 금지

## 렌즈 파일럿 (로드맵 5단계 — 구현 완료)

- **하루 한 장 5장**(`#lens/<id>`): 관심경제·플랫폼·고용vs프로젝트·학력vs증명·AI협업. 5단 구조(일상 훅 → 구조 그림 → '다르게 보면' 반대 렌즈 → 진로 연결 → 열린 질문) — 원칙 1을 테스트로 강제(단정 표현 금지, 반대 렌즈 필수, 열린 질문 종결)
- **노출 규칙**: 주 2~3회(7일 중 3일)만 홈 티저 노출, 푸시 없음. 날짜 결정적 순환으로 5일마다 5장 완주
- **열린 질문 한 줄 답**: 선택 입력, 위기 감지(`detectCrisis`) 경유 후 기기에만 저장 — 누적 신호의 시작
- **구조 한 줄 10개 직업분**(`#lens` 하단): 웹툰 작가·유튜버·개발자·교사·간호사·공무원·운동선수·의사·게임 개발자·1인 셀러 — "조건이 왜 이런지"의 시스템 차원 설명 + 렌즈 참조. 모듈 B(조건 대시보드) 구축 시 카드 하단 고정 슬롯으로 이동 예정
- 진입: K9 답변 L3 "렌즈 카드" 버튼 + 렌즈 요일 홈 티저 (기능을 입구에 내세우지 않음)

## 조건 대시보드 · 체험 지도 · 퀘스트 · 강점 저널 (구현 완료)

- **조건 카드(모듈 B v0, `#jobs`·`#job/<id>`)**: 직업 10개 — 가는 길/다른 문, 솔직한 조건, "AI가 못 하는 것", 구조 한 줄(렌즈 슬롯), 관련 답변 연결. **정직 원칙: 미검증 임금 수치 없음** — 임금 분포는 고용24 연동 후 표시(유일한 수치는 ①칩 검증치: 5년 생존율 36.4%, 또래 평균 임금 253.6만). 나침반 결과·렌즈 화면에서 진입
- **체험 지도(`#explore`)**: 검증된 공식 창구 9곳 시드, **개인 신청 필터 기본 ON**, 무료만, 재학 조건 미확인은 '확인' 표시. 100~200건 확충은 지역 체험처 검증 조사 후
- **탐험 퀘스트(`#quests`)**: 5역량(Krumboltz)+관찰 미션 15개, 완료 조건 = 앱 밖 행동 + 셀프 한 줄 인증(위기 감지 경유), 보상은 배지뿐. 강소·신기술 40%↑ 편성은 테스트로만 강제(UI 비노출)
- **강점 저널(`#journal`)**: 기분 1탭 체크인 — '불안·무거움'이면 케어 블록(설교 없음, 미션·도움 창구 연결) / "시간이 빨리 갔던 순간" 한 줄 기록(위기 감지 경유, 기기 저장, 삭제 가능, 랭킹·비교 없음). 10개 쌓이면 신호 리포트 예고

## 신호 리포트 · 첫 일자리 방패 (구현 완료)

- **신호 리포트(`#signal`)**: 나침반·역방향·저널·퀘스트·렌즈 답의 누적 흔적을 집계. 신호 3개부터 가설 제시 — 언제나 "확인해볼래요?"로 끝나는 가설(단정 금지, 테스트로 강제). 방향 정보 없이는 신호가 많아도 억지 가설을 만들지 않음. 가설 → 조건 카드·체험 지도(삼각검증: 내 신호+데이터+현실 접촉). 진입: 저널 하단
- **첫 일자리 방패(모듈 E, `#shield`)**: ① 최저임금·주휴수당 계산기(2026 시급 10,320원 — 고용노동부 검증, `shield.data.js`에서 연 1회 갱신) ② 근로계약서 필수 항목·위험 신호 ③ 첫 알바 전 체크리스트 10(저장됨) ④ 면접 무관 질문 알아채기 + "같은 일 같은 임금" 권리 프레임 ⑤ 도움 창구 연결. "법률 자문이 아니라 정보 안내" 명시. 진입: G3 답변 L3 버튼
